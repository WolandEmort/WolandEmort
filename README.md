## 🚀 Featured project

### [djinni-market-etl](https://github.com/WolandEmort/djinni-market-etl)

An ETL pipeline that collects IT job market statistics from Djinni and turns them into analytics-ready tables.

- **Extract:** Python scraper collecting vacancy and market stats
- **Load:** PostgreSQL as the warehouse
- **Transform:** dbt models (staging → marts) with tests
- **Run:** Docker / docker-compose for a reproducible local setup
- **Next:** deploy to AWS and collect daily snapshots to track market trends over time
